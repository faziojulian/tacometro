Convertidor de archivos bioMérieux Convierte corridas de VITEK MS PRIME (.mzML) en una lista de picos y un XML para importar en MicrobeNet

⚠ Leer antes de usar: esquema verificado contra un ejemplo real, con salvedades
La estructura del XML (MspMatchResult > ProjectInfo + Analytes > Analyte > Peaklist > Peaks > Peak, con sus atributos) se tomó de un archivo .xml real ya aceptado por MicrobeNet, no es una suposición. Aun así quedan puntos sin confirmar del todo:
  • El nombre de cada Analyte (campos name/externId) se reconstruye combinando datos del .mzML según el patrón observado en ese único archivo de ejemplo (instrumento, código de lámina, posición, tipo de muestra, etc.). Puede no generalizar a todos los casos (otros tipos de muestra, protocolos, etc.); por eso el campo "Nombre MSP" de cada muestra es editable a mano.
  • La versión de KB (base de conocimiento del Biotyper) no viaja en el .mzML de VITEK: hay que completarla manualmente en "Datos del proyecto" si se conoce.
  • El significado exacto de intensityScale en Peaklist no se pudo confirmar de forma independiente; se calcula como 1/intensidad máxima para que sea coherente con los picos normalizados (0 a 1) que sí se exportan siguiendo el mismo criterio del archivo de referencia.
  • La extracción de picos (m/z + intensidad) desde el .mzML es confiable de por sí: se basa en el estándar abierto mzML (HUPO-PSI). El CSV de picos exporta esos valores crudos (sin normalizar) como referencia adicional.
Antes de usar esto en producción, subí un lote de prueba a MicrobeNet y confirmá que lo acepta e identifica como se espera.

Ajustes de detección de picos
Si el .mzML ya trae el espectro centroidal (picos discretos, tal como lo entrega VITEK MS PRIME habitualmente), el umbral de ruido y la detección de picos por perfil no se aplican: se usan los picos tal cual vienen, filtrados por rango de m/z e intensidad.
Datos del proyecto (para el XML de MicrobeNet)
El UUID del proyecto y la cantidad de muestras se completan solos al generar el XML. "ID de instrumento" se autocompleta con el primer archivo cargado, pero se puede editar.
