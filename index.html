Convertidor de archivos bioMérieux Convierte corridas de VITEK MS PRIME (.mzML) en una lista de picos y un XML para importar en MicrobeNet

⚠ Leer antes de usar: el esquema XML es un borrador sin verificar
MicrobeNet no define un formato propio: espera el mismo XML que exporta el software Bruker MALDI Biotyper (carpeta HT-Out). Como el VITEK MS PRIME es de bioMérieux, esta página "traduce" el .mzML a un XML equivalente, pero no pude confirmar el esquema exacto que usa Bruker/MicrobeNet: el sitio microbenet.cdc.gov está bloqueado por la política de red de este entorno y no se contó con un archivo .xml real ya aceptado por MicrobeNet para calcarlo.
  • La extracción de picos (m/z + intensidad) desde el .mzML sí es confiable: se basa en el estándar abierto mzML (HUPO-PSI), no en una suposición.
  • El XML generado es una plantilla editable (función buildDraftXml en el código de esta página) marcada como borrador. Antes de subirlo a MicrobeNet, comparalo campo a campo contra un .xml real aceptado (pedilo a soporte del CDC/bioMérieux o a un colega con Biotyper) y ajustá los nombres de etiquetas si hace falta.
  • Mientras tanto, usá el CSV de picos como referencia confiable de lo que se extrajo del archivo.

Ajustes de detección de picos
Si el .mzML ya trae el espectro centroidal (picos discretos, tal como lo entrega VITEK MS PRIME habitualmente), el umbral de ruido y la detección de picos por perfil no se aplican: se usan los picos tal cual vienen, filtrados por rango de m/z e intensidad.
